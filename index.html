This is a two-step process: first scan and add every person to the list on the left, exactly as before; then, in the SAVED PEOPLE panel below, upload the company letterhead once and hit "Generate letters" — that one letterhead is used for every letter in the batch, so it doesn't matter whether you upload it before or after adding people. Upload the back of the card — the ID number and name are both read from its machine-readable strip, which is far more reliable than the printed labels on the front. If a PDF has the front and back as separate pages, that's fine — every page in the file gets scanned. If the ID number ever comes back empty, that's the tool declining to guess rather than risk showing the wrong number — check the raw scanned text below and enter it by hand. The letter date field prints onto every letter in the batch — leave it empty to leave that line blank instead. Every ID card image or PDF page you scanned for a person is kept and attached after their letter — front and back are combined onto a single sheet instead of one page each, and images are compressed for print-quality without bloating file size. Everything runs locally in this browser tab; nothing is uploaded anywhere. Each person gets their own PDF, named after their ID number — for one person you get a single PDF, for more than one you get a single ZIP file containing all of them, up to 30 at a time.
